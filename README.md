## 📖 О проекте

**КиберЛаб** — статический информационный сайт о вредоносных программах, защите учетных записей и базовых действиях при инциденте. Это образовательный материал, а не сервис проверки устройств или профессиональная консультация.

Рекомендации проверены 15 октября 2026 года. Для быстро меняющихся сведений на страницах приведены внешние справочные источники.

## 🎯 Основные Цели Проекта

✅ **Образование** - просвещение пользователей в области кибербезопасности

## 📄 Описание Файлов

### 🏠 `index.html` - Главная Страница

**Содержит основной контент сайта:**

#### 1️⃣ Hero-секция
- Заголовок о цифровой безопасности
- Описание цели сайта
- Кнопки навигации
- Привлекательная визуальная оформление

#### 2️⃣ Раздел "Что такое вредоносное ПО"
- Определение и описание
- Типы угроз
- Общие сведения

#### 3️⃣ Виды вредоносного ПО
Статические информационные карточки:
- **Вирусы и черви** - заражение файлов и распространение между устройствами
- **Трояны** - вредоносное ПО, маскирующееся под легитимное
- **Шифровальщики** - блокировка или шифрование данных с требованием выкупа
- **Шпионское ПО** - скрытый сбор сведений
- **Рекламное ПО** - нежелательная реклама и изменения браузера
- **Криптомайнеры** - несанкционированное использование ресурсов
- **Руткиты** - сокрытие компонентов и закрепление в системе
- **Drive-by download** - эксплуатация уязвимостей для загрузки или запуска кода

#### 4️⃣ Базовые меры защиты
- Обновление системы и приложений
- Резервное копирование важных файлов
- Уникальные пароли и многофакторная аутентификация
- Осторожность при работе со ссылками и загрузками

#### 5️⃣ Чек-лист Признаков Заражения
Примеры, которые могут требовать проверки:
- Резкое падение производительности
- Нежелательная реклама
- Неизвестные программы или неожиданное поведение
- Отключенная защита
- Исчезнувшие или зашифрованные файлы
- Необычный сетевой трафик или уведомления о входах в учетную запись

#### 6️⃣ Пошаговая Инструкция по Защите
1. Установка антивируса
2. Обновление операционной системы
3. Использование брандмауэра
4. Создание резервных копий
5. Обучение безопасности

#### 7️⃣ FAQ - Часто Задаваемые Вопросы
- Как защитить компьютер?
- Что делать, если произошло заражение?
- Какой антивирус выбрать?
- И другие актуальные вопросы

## 🚀 Быстрый Старт

### Предварительные Требования
- Современный браузер (Chrome, Firefox, Safari, Edge)
- Интернет-соединение (для загрузки шрифтов Google Fonts)
- Базовое понимание HTML/CSS/JS (для разработки)

### Установка

**Шаг 1: Клонируйте репозиторий**
```bash
git clone https://github.com/razetka2010/Digital-Security.git
cd Digital-Security
```

**Шаг 2: Откройте сайт в браузере**

*Вариант 1: Прямое открытие*
```bash
# macOS
open index.html

# Windows
start index.html

# Linux
xdg-open index.html
```

*Вариант 2: Локальный веб-сервер*
```bash
# Python 3
python -m http.server 8000

# Node.js (http-server)
npx http-server

# Затем откройте http://localhost:8000
```

## 🔒 Безопасность и Конфиденциальность

### Политика Конфиденциальности
- На сайте нет регистрации, форм отправки сообщений, комментариев или счетчиков посещаемости
- Шрифты и иконки загружаются с внешних серверов
- Хостинг-провайдер может обрабатывать технические журналы запросов по своим правилам

### Юридические Предупреждения
- Четкое определение ответственности
- Исключения и ограничения
- Условия использования
- Защита авторских прав

Данный сайт носит исключительно информационный характер. Авторы не несут ответственности за выбор программного обеспечения пользователями. Всегда скачивайте программы только с официальных сайтов!
