## 📖 О проекте

**КиберЛаб** — это современный информационный веб-сайт, посвящённый теме кибербезопасности и защите от вредоносных программ. Проект создан **сообществом "Знание Севера"** с целью информирования и образования пользователей о различных типах цифровых угроз и методах защиты в 2026 году.

Сайт объединяет актуальную информацию о киберугрозах, практические рекомендации и честное руководство по выбору решений для защиты.

- Современный браузер (Chrome, Firefox, Safari, Edge)
- Интернет-соединение (для загрузки шрифтов Google Fonts)
- Базовое понимание HTML/CSS/JS (для разработки)

### Установка

**Шаг 1: Клонируйте репозиторий**
```bash
git clone https://github.com/razetka2010/Digital-Security.git
cd Digital-Security
```

**Шаг 2: Откройте сайт в браузере**

*Вариант 1: Прямое открытие*
```bash
# macOS
open index.html

# Windows
start index.html

# Linux
xdg-open index.html
```

*Вариант 2: Локальный веб-сервер*
```bash
# Python 3
python -m http.server 8000

# Node.js (http-server)
npx http-server

# Затем откройте http://localhost:8000
```
